# Сайт спортивного клуба каратэ «Сэнкё»

Официальный веб-сайт МОО «Спортивный клуб «СЭНКЁ» (JKS Belarus, Минск). 

Проект представляет собой полнофункциональный веб-сервис с адаптивным клиентским интерфейсом, выполненным в стилистике традиционных японских мотивов, и закрытой панелью управления контентом (админкой).

---

## Основной стек

- **Backend:** Node.js, Express.js
- **База данных:** MySQL (драйвер `mysql2/promise`)
- **Авторизация:** JWT (JSON Web Tokens), `bcryptjs` для хеширования паролей
- **Загрузка файлов:** Multer
- **Frontend:** Нативный JavaScript (ES6+), HTML5, семантический модульный CSS3
- **Редактор контента:** Quill.js (WYSIWYG-редактор для статей и новостей)
- **Интеграции:** YouTube Data API v3 (вывод актуальных видеороликов с клубного канала)

## Возможности и функционал

### Публичная часть
- **Расписание тренировок:** фильтрация по сезонам (зима/лето), дням недели, времени и возрастным группам.
- **Статьи и материалы:** каталог публикаций с поддержкой прикрепления файлов для скачивания (методички, регламенты) и системой древовидных комментариев с ответами на отзывы.
- **Новости клуба:** актуальные события, фотоотчёты и анонсы соревнований.
- **Тренерский состав:** карточки инструкторов с описанием квалификации, данов и спортивных званий.
- **Отзывы:** раздел отзывов воспитанников и родителей с модерацией через админ-панель.
- **YouTube-галерея:** автоматическая подгрузка последних видео с официального канала клуба через Google API.

### Панель администратора (`/admin.html`)
- Авторизация через защищённый диалог по JWT-токену с сохранением в `localStorage`.
- Разделение прав доступа: обычный администратор и супер-администратор (управление учётными записями администраторов).
- CRUD-операции для всех разделов:
  - Редактирование расписания
  - Публикация и удаление статей с возможностью прикреплять файлы
  - Управление новостной лентой
  - Редактирование списка тренеров и загрузка фотографий
  - Модерация отзывов
  - Встроенный rich-text редактор Quill для форматирования текста

## Установка и запуск

### 1. Требования
- Node.js версии 18+
- MySQL Server 8.0+

### 2. Клонирование и настройка базы данных
1. Создайте базу данных и выполните скрипт инициализации:
   ```bash
   mysql -u root -p < Project-MySQL/database/mysql_init.sql
   ```
   Скрипт создаст структуру таблиц `karate_club` и наполнит её начальными данными (тренеры, расписание, базовый контент).

### 3. Настройка переменных окружения
Перейдите в каталог бэкенда:
```bash
cd Project-MySQL/backend
```

Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```

Заполните актуальные данные в `.env`:
```env
PORT=3000
NODE_ENV=development

# Секрет для подписи JWT-токенов
JWT_SECRET=ваш_секретный_ключ_от_32_символов
JWT_EXPIRES_IN=24h

# Подключение к MySQL
DB_HOST=localhost
DB_PORT=3306
DB_NAME=karate_club
DB_USER=ваш_пользователь_бд
DB_PASSWORD=ваш_пароль_бд
DB_SSL=false

# YouTube Data API (опционально)
YOUTUBE_API_KEY=ваш_ключ_api
YOUTUBE_CHANNEL_ID=id_канала

# Учётные данные администратора по умолчанию
DEFAULT_ADMIN_LOGIN=admin
DEFAULT_ADMIN_PASSWORD=ваш_пароль_админа
```

> Генерация надёжного JWT_SECRET в консоли:
> ```bash
> node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
> ```

### 4. Установка зависимостей и старт
```bash
npm install
npm start
```

После запуска сервер будет доступен по адресу:  
`http://localhost:3000`

## Основные API-эндпоинты

| Метод | Путь | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/admin/login` | Авторизация администратора, выдача JWT | Публичный |
| `GET` | `/api/admin/session` | Проверка валидности текущего JWT-токена | Публичный / Bearer |
| `GET`, `POST` | `/api/admins` | Получение списка и создание администраторов | SuperAdmin |
| `PUT`, `DELETE` | `/api/admins/:id` | Редактирование / удаление администратора | SuperAdmin |
| `GET` | `/api/schedule` | Получение расписания (с фильтрами `?season=summer` / `?all=1`) | Публичный |
| `POST`, `PUT`, `DELETE` | `/api/schedule` | Управление расписанием | Авторизован (JWT) |
| `GET` | `/api/articles` | Список статей | Публичный |
| `GET` | `/api/articles/:id` | Просмотр статьи и комментариев | Публичный |
| `POST` | `/api/articles/:id/comments` | Добавление комментария к статье | Публичный |
| `POST`, `PUT`, `DELETE` | `/api/articles` | Создание, правка, удаление статей и вложений | Авторизован (JWT) |
| `GET` | `/api/news` | Список новостей | Публичный |
| `POST`, `PUT`, `DELETE` | `/api/news` | Управление новостями | Авторизован (JWT) |
| `GET` | `/api/instructors` | Список тренеров | Публичный |
| `POST`, `PUT`, `DELETE` | `/api/instructors` | Управление тренерами | Авторизован (JWT) |
| `GET` | `/api/reviews` | Список отзывов | Публичный |
| `POST`, `PUT`, `DELETE` | `/api/reviews` | Добавление / удаление отзывов | Авторизован (JWT) |
| `GET` | `/api/download/:filename` | Безопасное скачивание прикреплённых файлов | Публичный |
| `GET` | `/api/config/public` | Получение публичной конфигурации (YouTube ID) | Публичный |
